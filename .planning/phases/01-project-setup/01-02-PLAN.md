**Install Express 5 in packages/server:**
Run `npm install express@5 --workspace=packages/server` and `npm install --save-dev @types/express@5 --workspace=packages/server`.

**Replace packages/server/src/index.ts** with a real Express 5 dev server stub:

```typescript
import express from 'express'

const app = express()
const port = Number(process.env.PORT ?? 3001)

app.use(express.json())

// Health endpoint — required by Trajectory REST protocol
app.get('/trajectory/v1/health', (_req, res) => {
  res.json({ status: 'ok', timestamp: new Date().toISOString() })
})

app.listen(port, () => {
  console.log(`Trajectory Action Server listening on http://localhost:${port}`)
})
```

Do NOT add `export default app` — Express 5 with `"type": "module"` requires the server to be a self-contained entry point. The express import uses ESM natively in Express 5.

**Create apps/console/vite.config.ts** with React plugin and dev proxy:

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    proxy: {
      '/trajectory': {
        target: 'http://localhost:3001',
        changeOrigin: true,
      },
      '/management': {
        target: 'http://localhost:3001',
        changeOrigin: true,
      },
    },
  },
})
```

No path rewriting needed — both console and server use the same API path prefixes.

**Install dev dependencies at root:**
Run `npm install --save-dev concurrently tsx` at the repo root.

**Update root package.json scripts** — add/update these scripts (keep existing build/test scripts):

```json
{
  "scripts": {
    "build": "tsc --build",
    "dev": "concurrently --kill-others-on-fail --names \"server,console\" -c \"blue,green\" \"npm run dev:server\" \"npm run dev:console\"",
    "dev:server": "tsx watch packages/server/src/index.ts",
    "dev:console": "npm run dev --workspace=apps/console",
    "test": "vitest run",
    "test:watch": "vitest"
  }
}
```

The `--names` flag labels output lines; `-c` colors them. `--kill-others-on-fail` ensures both processes stop if either crashes.

**Update packages/server/package.json** — verify `@types/node` is in devDependencies (should already be from Plan 01, but confirm it exists).

**Install linting and formatting dependencies at root:**
```bash
npm install --save-dev eslint @eslint/js typescript-eslint eslint-config-prettier prettier husky lint-staged
```

**Create eslint.config.mjs** at repo root:

```javascript
import eslint from '@eslint/js'
import tseslint from 'typescript-eslint'
import prettierConfig from 'eslint-config-prettier'

export default tseslint.config(
  eslint.configs.recommended,
  ...tseslint.configs.recommended,
  prettierConfig,
  {
    ignores: ['**/dist/**', '**/node_modules/**', '**/*.d.ts', 'packages/python-sidecar/**'],
  }
)
```

Use `typescript-eslint` (the unified package for ESLint 9 flat config), NOT the separate `@typescript-eslint/eslint-plugin` + `@typescript-eslint/parser` packages.

**Create .prettierrc.json** at repo root:

```json
{
  "semi": false,
  "singleQuote": true,
  "trailingComma": "es5",
  "printWidth": 100,
  "tabWidth": 2
}
```

**Add lint and format scripts** to root package.json:

```json
{
  "scripts": {
    "lint": "eslint .",
    "lint:fix": "eslint . --fix",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "prepare": "husky"
  }
}
```

**Add lint-staged config** to root package.json:

```json
{
  "lint-staged": {
    "*.{ts,tsx}": ["eslint --fix", "prettier --write"],
    "*.{json,md,yml,yaml,css,html}": ["prettier --write"]
  }
}
```

**Initialize husky:**
Run `npx husky init` from the repo root. This creates `.husky/` directory and adds `"prepare": "husky"` to package.json (verify it exists after).

**Edit .husky/pre-commit** to contain exactly:

```sh
npx lint-staged
```

(Replace the default `npm test` that husky init creates.)

**Create .github/workflows/ci.yml:**

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  ci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - run: npm test
      - run: npm run lint
      - run: npm run format:check
```

**Run Prettier on the entire codebase** after all configs are in place:

```bash
npx prettier --write .
```

This ensures all existing files match the configured style before the first commit with lint-staged active.
