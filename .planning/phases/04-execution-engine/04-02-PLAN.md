Create `packages/engine/src/instance-manager/instance-manager.ts` implementing the central orchestrator:

```typescript
import type BetterSqlite3 from 'better-sqlite3'
import type { Instance } from '@trajectory/storage'
import {
  InstanceRepository,
  ActionRepository,
  EnvironmentRepository,
  CodeVersionRepository,
  LogRepository,
  SettingsRepository,
} from '@trajectory/storage'
```

**Constructor:**

- Accepts `(db: BetterSqlite3.Database, options: InstanceManagerOptions)`
- Creates all 6 repository instances from `db`
- Creates `ExecutionLogger` from the repos
- Reads `python_pool_size` from SettingsRepository (fallback to `options.poolSize ?? 4`)
- Creates `PythonWorkerPool` with `{ pythonPath: options.pythonPath ?? 'python', scriptPath: options.scriptPath, poolSize }`
- Creates `StateMachine` with all repos, the retrying code executor, and callbacks:
  - `onStateChange`: forwards to `options.onStateChange` if provided
  - `onTerminal`: calls `this.executionLogger.writeLog(instanceId, state, instance)`, then forwards to `options.onTerminal`
  - `onError`: forwards to `options.onError` if provided
- Pass `actionRepo` and `environmentRepo` as the new optional params to StateMachine constructor

**Private method: `makeRetryingExecutor()`**
Returns a `CodeExecutor` that wraps `this.pool.executeCode.bind(this.pool)`:

- Call the pool's executeCode
- If result is not success AND `error_type === 'WORKER_CRASH'` AND state is NOT in `RETRY_EXEMPT_STATES` (Set of `'ABORTING'`, `'STOPPING'`, `'CLEARING'`): retry once by calling pool.executeCode again
- Otherwise return the original result
- For retry on `RUNTIME_ERROR` (CONTEXT.md says "Python exception: same as crash — retry once"): also retry on `error_type === 'RUNTIME_ERROR'` with the same exempt-state check. This matches the user's locked decision exactly.
- Return the retry result (whether it succeeds or fails)

**Private method: `pinCodeVersions(actionOid: string)`**

- Call `this.codeVersionRepo.getAllActiveVersions(actionOid)` to get all active versions for this action
- Map to `Array<{ state: string; code_version_id: string }>` — one entry per active version
- Return the array (may be empty if no code versions exist)

**Public method: `async invoke(request: InvokeRequest): Promise<InvokeResult>`**

1. Validate action exists: `this.actionRepo.findByOid(request.action_oid)`. If null, throw `EngineError('ACTION_NOT_FOUND', ...)`
2. Resolve parameters: `resolveInputParameters(request.input_parameters, action.input_parameter_specifications)`
3. Pin code versions: `this.pinCodeVersions(request.action_oid)`
4. Create instance via `this.instanceRepo.create({...})`:
   - NOTE: `InstanceRepository.create()` generates its own UUID internally (ignores `runtime_action_instance_id` from InstanceInput). Pass any string for that field; read the returned instance for the actual UUID.
   - `action_oid`: request.action_oid
   - `environment_oid`: action.environment_oid
   - `workflow_instance_id`: request.workflow_instance_id
   - `step_instance_id`: request.step_instance_id
   - `step_oid`: request.step_oid
   - `visibility`: action.action_visibility
   - `state`: `action.action_visibility === 'observable' ? 'STARTING' : 'POSTED'`
   - `input_parameters`: resolvedInputs (the array of {key, value})
   - `output_parameters`: `[]`
   - `state_history`: `[]` (InstanceRepository.create() builds initial history itself)
   - `pinned_code_versions`: pinnedVersions
   - `states_with_code_executed`: `[]`
5. Start async execution — DO NOT AWAIT:
   ```typescript
   this.stateMachine.startInstance(instance.runtime_action_instance_id).catch((err) => {
     console.error(`State machine error for instance ${instance.runtime_action_instance_id}:`, err)
     this.callbacks?.onError?.(
       instance.runtime_action_instance_id,
       err instanceof Error ? err : new Error(String(err))
     )
   })
   ```
   Store callbacks reference as `private readonly callbacks` in constructor.
6. Return `InvokeResult` with the instance's actual UUID, action_oid, status (initial state), created_at, and sse_endpoint (only for observable: `/trajectory/v1/instances/${id}/events`)

**Public method: `async sendCommand(instanceId: string, command: string): Promise<void>`**

- Delegate to `this.stateMachine.sendCommand(instanceId, command)`

**Public method: `getInstance(instanceId: string): Instance | null`**

- Return `this.instanceRepo.findById(instanceId)`

**Public method: `getActiveInstances(): Instance[]`**

- Return `this.instanceRepo.findActive()`

**Public method: `resizePool(newSize: number): void`**

- Call `this.pool.resize(newSize)`

**Public method: `async shutdown(): Promise<void>`**

- Call `await this.pool.shutdown()`

**Public getters:**

- `poolSize`: returns `this.pool.targetPoolSize`
- `poolStatus`: returns `{ size: this.pool.size, idle: this.pool.idleCount, busy: this.pool.busyCount, queued: this.pool.queueLength }`
