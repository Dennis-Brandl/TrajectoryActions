  <action>
    1. Create `apps/console/src/features/environments/hooks.ts`:
       - `useEnvironments()` — useQuery with queryKey ['environments'], calls api.environments()
       - `useUploadPackage()` — useMutation calling api.upload(file), onSuccess invalidates queryKey ['environments']
       - `useDeleteEnvironment()` — useMutation calling api.deleteEnvironment(oid), onSuccess invalidates queryKey ['environments']

    2. Create `apps/console/src/features/environments/UploadDialog.tsx`:
       - Use shadcn Dialog component
       - Inside the dialog content, render a react-dropzone zone:
         ```tsx
         accept: { 'application/octet-stream': ['.WFenvir', '.WFaction'] }
         maxFiles: 1
         ```
       - Client-side extension validation in onDrop callback as safety net (file.name.endsWith('.WFenvir') || file.name.endsWith('.WFaction'))
       - On valid drop: call uploadMutation.mutateAsync(file)
       - Display states:
         a. Idle: "Drag .WFenvir or .WFaction file here, or click to select" with dashed border
         b. Drag active: border color change to blue, "Drop the file here"
         c. Uploading: show spinner/loading indicator from mutation.isPending
         d. Success: show upload result — list of environments with name, OID, action count, and status (created/updated). Use Badge components for status.
         e. Error: show error message from mutation.error.message in red
       - Close button resets state
       - CRITICAL: Do NOT set Content-Type header on the FormData fetch — the browser sets the multipart boundary automatically

    3. Create `apps/console/src/features/environments/EnvironmentsPage.tsx`:
       - Page title: "Environments" with "Upload Package" button (opens UploadDialog)
       - Loading state: skeleton cards
       - Error state: error message
       - Empty state: "No environments imported yet. Upload a .WFenvir or .WFaction package to get started."
       - For each environment, render a shadcn Card (from ManagementConsoleSpec.md section 3.2):
         - Name and version in card header
         - OID displayed (truncated or full, monospace)
         - Action count (e.g., "5 actions")
         - Import date formatted (e.g., "Feb 21, 2026")
       - Each card is clickable — navigates to `/environments/${env.oid}` using Link from react-router
       - Cards in responsive grid: grid-cols-1 md:grid-cols-2 lg:grid-cols-3
       - Include a delete button (icon) on each card with confirmation dialog (optional: simple window.confirm)

  </action>

    - `cd apps/console && npx vite build` succeeds

    - hooks.ts exports useEnvironments, useUploadPackage, useDeleteEnvironment
  </verify>
