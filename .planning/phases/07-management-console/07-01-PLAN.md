    3. Update `apps/console/vite.config.ts`:

       ```css

       ```

       ```bash
       npx shadcn@latest init -d
       ```
       The `-d` flag uses defaults (new-york style, zinc base color, CSS variables). If the CLI prompts interactively despite `-d`, use: `npx shadcn@latest init --style new-york --base-color zinc --css-variables --force`


    - shadcn init WILL FAIL if baseUrl/paths are not in tsconfig.json — step 2 must complete before step 5
    - Tailwind v4 does NOT use tailwind.config.js or PostCSS config — it uses the @tailwindcss/vite plugin and @import "tailwindcss" in CSS
    - The vite-plugin-monaco-editor default export may need `(monacoEditorPlugin as any).default({})` if the types mismatch — check the import shape.     - Do NOT set verbatimModuleSyntax to true — the existing false value is an intentional project decision

       ```typescript
       const BASE = '/management/v1'

       async function apiFetch<T>(path: string, init?: RequestInit): Promise<T> {
         const res = await fetch(`${BASE}${path}`, init)
         if (!res.ok) {
           const err = await res.json().catch(() => ({ error: { message: res.statusText } }))
           throw new Error(err?.error?.message ?? `HTTP ${res.status}`)
         }
         return res.json() as Promise<T>
       }
       ```
