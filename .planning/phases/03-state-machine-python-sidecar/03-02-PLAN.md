The file structure:

```
imports (sys, json, io, contextlib, traceback, time)
MAX_OUTPUT_BYTES constant (64KB = 64 * 1024)
run_user_code() function
main() function with stdin read loop
if __name__ == '__main__': main()
```

**Constants:**

- `MAX_OUTPUT_BYTES = 64 * 1024` — cap per CONTEXT.md (~64KB for stdout/stderr capture)

**`run_user_code(source_code, inputs, outputs, props, action_props)`:**

- Step 1: `compile(source_code, '<action_code>', 'exec')` — raises SyntaxError for structural issues
- Step 2: Create `stdout_buf = io.StringIO()` and `stderr_buf = io.StringIO()`
- Step 3: Create namespace `{'__builtins__': __builtins__}` — full Python access per CONTEXT.md
- Step 4: Execute the compiled code in the namespace with redirected stdout/stderr:
  ```python
  with contextlib.redirect_stdout(stdout_buf), contextlib.redirect_stderr(stderr_buf):
      exec(code_obj, namespace)
  ```
  This defines the `execute()` function in the namespace.
- Step 5: Extract the `execute` function from namespace. If not found or not callable, raise `RuntimeError("User code must define a callable 'execute' function")`
- Step 6: Call `execute(inputs, outputs, props, action_props)` with stdout/stderr still redirected:
  ```python
  with contextlib.redirect_stdout(stdout_buf), contextlib.redirect_stderr(stderr_buf):
      return_value = execute_fn(inputs, outputs, props, action_props)
  ```
- Step 7: Read captured output. Truncate if over MAX_OUTPUT_BYTES (check `.encode('utf-8')` length, truncate and append `'\n[stdout truncated]'` or `'\n[stderr truncated]'`).
- Step 8: Return `(return_value, stdout_text, stderr_text)`

**`main()`:**

- Read lines from `sys.stdin` using `for line in sys.stdin:` loop
- For each line:
  a. Strip whitespace. Skip empty lines.
  b. Record `start_ms = time.time() * 1000`
  c. Try to `json.loads(line)`. On `JSONDecodeError`, write error response with `request_id: None`, `error_type: 'RUNTIME_ERROR'`, and continue.
  d. Extract fields from request:
  - `request_id = request.get('request_id')`
  - `source_code = request.get('source_code', '')`
  - `inputs = request.get('inputs', {})`
  - `outputs = {}` — starts empty; inputs is read-only. outputs accumulates across states but the sidecar sees only the current state's outputs (the engine passes accumulated outputs from previous states via the request if needed). Actually per ExecutionEngineSpec.md §2.5, outputs accumulate. But in the sidecar, outputs starts empty and code writes to it. The ENGINE is responsible for passing accumulated outputs from prior states.
    Wait — re-read the spec. The engine should pass the current accumulated outputs to the sidecar, and the sidecar passes them through to `execute()`. User code can read previously set values AND write new ones.
    So: `outputs = dict(request.get('outputs', {}))` — copy the accumulated outputs from the request. User code modifies this dict. The response sends back the full (possibly modified) dict.
  - `props = request.get('environment_action_properties', {})`
  - `action_props = request.get('action_properties', {})`
    e. Try to call `run_user_code(source_code, inputs, outputs, props, action_props)`:
  - On success: build success response with `success: True`, `outputs: outputs`, `return_value: return_value`, `execution_time_ms`, `stdout_capture`, `stderr_capture`
  - On `SyntaxError`: build error response with `error_type: 'SYNTAX_ERROR'`, `error: f'{type(e).__name__}: {e}'`, `traceback: traceback.format_exc()`
  - On any other `Exception`: build error response with `error_type: 'RUNTIME_ERROR'`, `error: f'{type(e).__name__}: {e}'`, `traceback: traceback.format_exc()`
    f. Write response: `print(json.dumps(response), flush=True)` — flush=True is critical for the Node.js parent to receive output immediately

**Response format (success):**

```json
  "traceback": "Traceback ...",

}
```

**Helper function:**

```python
def send_request(proc, request_dict):
    """Send a JSON request to the worker and read one JSON response."""
    line = json.dumps(request_dict) + '\n'
    proc.stdin.write(line)
    proc.stdin.flush()
    response_line = proc.stdout.readline()
    return json.loads(response_line)
```

**Setup:** In setUpClass, spawn `python -u sandbox_runner.py` with `subprocess.Popen(stdin=PIPE, stdout=PIPE, stderr=PIPE)`. In tearDownClass, terminate the process.

**Tests:**

a. **test_happy_path_returns_true:**
Send request with source_code:
`python
      def execute(inputs, outputs, props, action_props):
          outputs["greeting"] = "hello " + inputs.get("name", "world")
          return True
      `
inputs: `{"name": "Alice"}`
Assert: success is True, return_value is True, outputs["greeting"] == "hello Alice"

b. **test_return_false_for_hold:**
Send request with source_code:
`python
      def execute(inputs, outputs, props, action_props):
          return False
      `
Assert: success is True, return_value is False

c. **test_syntax_error:**
Send request with source_code: `def execute(inputs, outputs, props, action_props)\n    return True` (missing colon)
Assert: success is False, error_type == "SYNTAX_ERROR", error contains "SyntaxError", traceback is non-empty

d. **test_runtime_error:**
Send request with source_code:
`python
      def execute(inputs, outputs, props, action_props):
          raise ValueError("bad input")
      `
Assert: success is False, error_type == "RUNTIME_ERROR", error contains "ValueError: bad input", traceback is non-empty

e. **test_missing_execute_function:**
Send request with source_code: `x = 42` (no execute function)
Assert: success is False, error_type == "RUNTIME_ERROR", error contains "execute"

f. **test_stdout_capture:**
Send request with source_code:
`python
      def execute(inputs, outputs, props, action_props):
          print("debug info")
          return True
      `
Assert: success is True, stdout_capture == "debug info\n", the JSON protocol is not corrupted (print goes to capture, not to protocol stdout)

g. **test_stderr_capture:**
Send request with source_code:
`python

      def execute(inputs, outputs, props, action_props):
          print("warning", file=sys.stderr)
          return True
      `
Assert: success is True, stderr_capture == "warning\n"

h. **test_outputs_mutation:**
Send request with source_code:
`python
      def execute(inputs, outputs, props, action_props):

          outputs["b"] = "2"

      `
Assert: outputs == {"a": "1", "b": "2"}

i. **test_outputs_accumulation:**
Send request with outputs: `{"prior": "value"}` and source_code that reads and adds:
`python

          return True
      `
Assert: outputs contains both "prior": "value" and "new": "value_extended"

j. **test_multiple_sequential_requests:**
Send 3 requests to the same worker process. Verify all 3 return correct results. This proves the worker loop handles multiple requests without restarting.

k. **test_execution_time_ms:**
Send a request. Assert: execution_time_ms is a number >= 0.

l. **test_request_id_passthrough:**
Send request with request_id: "my-test-id". Assert: response request_id == "my-test-id".

n. **test_invalid_json_request:**
Write a non-JSON line to stdin. Assert: response has success:false, request_id:null.
