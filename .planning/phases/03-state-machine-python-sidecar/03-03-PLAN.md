<objective>
Build the Python worker pool — PythonWorker (single subprocess wrapper), PythonWorkerPool (N-worker manager with acquire/release), and the CodeExecutor bridge that connects the state machine to real Python execution. Includes worker lifecycle management: crash recovery, recycling after N executions, SIGTERM/SIGKILL for ABORT.

Purpose: This is the Node.js side of the Python execution bridge. The state machine (Plan 03-01) calls `codeExecutor()` which routes to a PythonWorkerPool, which acquires an idle worker, sends the request via stdin JSON, and returns the response. This plan also handles the operational concerns: what happens when a worker crashes, when it needs recycling, and when the engine needs to kill a running execution (ABORT/STOP).
Output: PythonWorker and PythonWorkerPool classes with full lifecycle management, tested against the real sandbox_runner.py from Plan 03-02.

```typescript
export interface SidecarRequest {
  request_id: string
  action_oid: string
  action_name: string
  state: string
  source_code: string
  inputs: Record<string, string>
  outputs: Record<string, string>
  environment_action_properties: Record<string, Record<string, string>>
  action_properties: Record<string, Record<string, string>>
  timeout_ms: number
}

export interface SidecarResponse {
  request_id: string
  success: boolean
  outputs: Record<string, string>
  return_value: boolean | null
  execution_time_ms: number
  stdout_capture: string
  stderr_capture: string
  // Error fields (present when success is false)
  error?: string
  error_type?: 'SYNTAX_ERROR' | 'RUNTIME_ERROR' | 'TIMEOUT' | 'WORKER_CRASH'
  traceback?: string
}
```

2. Create `packages/engine/src/python-pool/worker.ts`:
   Import `spawn` from `node:child_process`, `createInterface` from `node:readline`, `randomUUID` from `node:crypto`, and the types from `./types.js`.

   **PythonWorker class:**
   - Constructor params:
     - `pythonPath: string` — path to Python binary (default `'python'`)
     - `scriptPath: string` — path to sandbox_runner.py
   - Constructor body:
     - Spawn: `this.process = spawn(pythonPath, ['-u', scriptPath], { stdio: ['pipe', 'pipe', 'pipe'] })`
     - Set up readline on stdout: `this.rl = createInterface({ input: this.process.stdout! })`
     - Wire up `rl.on('line', ...)` handler:
       - If `this.pendingResolve` exists and line is non-empty:
         - Try `JSON.parse(line)` as `SidecarResponse`
         - Call `this.pendingResolve(response)`
         - Clear pending resolve/reject
       - On parse error: call `this.pendingReject(new Error(...))`
     - Wire up `this.process.on('error', ...)`:
       - If `pendingReject` exists, call it with the error
     - Wire up `this.process.on('close', (code) => ...)`:
       - Set `this._isDead = true`
       - If `pendingReject` exists, call it with `new Error('Worker crashed with exit code ${code}')`
       - Emit `'close'` event (so pool can detect crash and replace)
     - Collect stderr for diagnostics: `this.process.stderr!.on('data', (chunk) => { this.stderrBuffer += chunk.toString() })`
       - Cap stderrBuffer at 64KB

   - Private state:
     - `process: ChildProcess`
     - `rl: readline.Interface`
     - `pendingResolve?: (result: SidecarResponse) => void`
     - `pendingReject?: (err: Error) => void`
     - `_isDead = false`
     - `_executionCount = 0`
     - `stderrBuffer = ''`
     - `_busy = false`

   - **`async execute(request: SidecarRequest): Promise<SidecarResponse>`**
     - If `_isDead`, throw `new Error('Cannot execute on a dead worker')`
     - If `_busy`, throw `new Error('Worker is already executing')`
     - Set `_busy = true`
     - Return a new Promise:
       - Set `pendingResolve` and `pendingReject`
       - Write `JSON.stringify(request) + '\n'` to `this.process.stdin!`
       - Increment `_executionCount`
     - In `.finally()`: set `_busy = false`
     - Add timeout handling:
       - Set a `setTimeout` for `request.timeout_ms + 5000` (grace period beyond the Python-side timeout)
       - If timeout fires before response: reject with timeout error, set error_type to TIMEOUT

   - **`kill(signal: NodeJS.Signals = 'SIGTERM'): void`**
     - Call `this.process.kill(signal)`

   - **`async killWithGrace(gracePeriodMs = 5000): Promise<void>`**
     - Send SIGTERM
     - Set timeout for `gracePeriodMs`
     - If process doesn't close within grace period, send SIGKILL
     - Wait for 'close' event
     - Per RESEARCH.md: on Windows SIGTERM behaves like SIGKILL — acceptable since production is Linux

   - **Getters:**
     - `get isDead(): boolean` — `this._isDead`
     - `get isBusy(): boolean` — `this._busy`
     - `get executionCount(): number` — `this._executionCount`
     - `get pid(): number | undefined` — `this.process.pid`

   - **`dispose(): void`**
     - Close readline interface
     - Kill process if still alive
     - Clean up listeners

1. Create `packages/engine/src/python-pool/pool.ts`:
   Import PythonWorker, types, and CodeExecutionResult from the state machine types.

**PythonWorkerPool class:**

- Constructor params:
  - `options: { pythonPath?: string; scriptPath: string; poolSize: number; maxExecutionsPerWorker?: number }`
  - Defaults: `pythonPath = 'python'`, `maxExecutionsPerWorker = 100`
- Constructor body:
  - Store options
  - Create `poolSize` workers, add to `idleWorkers: PythonWorker[]`
  - Wire each worker's process 'close' event to `handleWorkerCrash(worker)`

- Private state:
  - `idleWorkers: PythonWorker[]`
  - `busyWorkers: Set<PythonWorker>`
  - `waitQueue: Array<{ resolve: (worker: PythonWorker) => void }>` — FIFO queue for when all workers busy
  - `isShuttingDown: boolean`

- **`async acquire(): Promise<PythonWorker>`**
  - If `isShuttingDown`, throw `new Error('Pool is shutting down')`
  - If `idleWorkers.length > 0`:
    - Pop a worker from idleWorkers
    - Add to busyWorkers
    - Return it
  - Else (all workers busy):
    - Return a Promise that is added to `waitQueue`
    - When a worker becomes available (via `release()`), the queue's oldest promise is resolved

- **`release(worker: PythonWorker): void`**
  - Remove from busyWorkers
  - Check if worker should be recycled:
    - If `worker.executionCount >= maxExecutionsPerWorker` OR `worker.isDead`:
      - Kill worker (if alive)
      - Spawn a replacement worker
      - The replacement goes to idle or serves queue
    - Else: return worker to idle or serve queue
  - Serve queue: if `waitQueue.length > 0`, shift the first waiter and resolve with the available worker (add to busyWorkers)
  - Else: add worker to idleWorkers

- **`handleWorkerCrash(worker: PythonWorker): void`** (private)
  - Called when a worker's subprocess exits unexpectedly
  - Remove from idleWorkers or busyWorkers (whichever it's in)
  - If not shutting down, spawn a replacement
  - Note: if the worker was busy, its pending execute() promise already rejected via the PythonWorker 'close' handler

- **`spawnWorker(): PythonWorker`** (private)
  - Create new PythonWorker with stored pythonPath and scriptPath
  - Wire 'close' event to handleWorkerCrash
  - Return the worker

- **`async executeCode(instanceId: string, state: string, sourceCode: string, inputs: Record<string, string>, outputs: Record<string, string>, envProps: Record<string, unknown>, actionProps: Record<string, unknown>, timeoutMs: number): Promise<CodeExecutionResult>`**
  This method implements the `CodeExecutor` interface from Plan 03-01. It:
  a. Acquires a worker: `const worker = await this.acquire()`
  b. Builds a `SidecarRequest`:

  ```typescript
  const request: SidecarRequest = {
    request_id: randomUUID(),
    action_oid: '', // Populated by caller in Phase 4
    action_name: '',
    state,
    source_code: sourceCode,
    inputs,
    outputs,
    environment_action_properties: envProps as Record<string, Record<string, string>>,
    action_properties: actionProps as Record<string, Record<string, string>>,
    timeout_ms: timeoutMs,
  }
  ```

  c. Calls `await worker.execute(request)`
  d. In `.finally()`: calls `this.release(worker)`
  e. Maps the `SidecarResponse` to `CodeExecutionResult`:

  ```typescript
  return {
    success: response.success,
    outputs: response.outputs,
    return_value: response.return_value,
    error: response.error,
    error_type: response.error_type,
    traceback: response.traceback,
    execution_time_ms: response.execution_time_ms,
    stdout_capture: response.stdout_capture,
    stderr_capture: response.stderr_capture,
  }
  ```

  f. If worker.execute() rejects (crash), catch and return a WORKER_CRASH CodeExecutionResult:

  ```typescript
  return {
    success: false,
    outputs: {},
    return_value: null,
    error: err.message,
    error_type: 'WORKER_CRASH',
    execution_time_ms: 0,
    stdout_capture: '',
    stderr_capture: '',
  }
  ```

- **`async killWorker(instanceId: string): Promise<void>`**
  Find the busy worker serving this instanceId (need to track which instance each worker is serving — add a `Map<string, PythonWorker>` for instanceId -> worker mapping).
  Actually, the simpler approach: the caller (state machine) holds a reference to the execution promise and can use AbortController or similar. But for ABORT, the state machine needs to kill the worker that's running code for a specific instance.

  Better approach: `executeCode` tracks the mapping. Add `private activeExecutions: Map<string, PythonWorker>` mapping instanceId to the worker currently executing for it. In executeCode, set `activeExecutions.set(instanceId, worker)` before execute, delete in finally.

  `killWorker(instanceId)` then: looks up worker in activeExecutions, calls `worker.killWithGrace()`, removes from activeExecutions. The worker's pending promise will reject, and handleWorkerCrash will spawn a replacement.

- **`async shutdown(): Promise<void>`**
  - Set `isShuttingDown = true`
  - Reject all waitQueue entries
  - Kill all idle workers
  - Wait for all busy workers to finish (with a timeout), then kill remaining
  - Dispose all workers

- **Getters:**
  - `get size(): number` — total workers (idle + busy)
  - `get idleCount(): number`
  - `get busyCount(): number`
  - `get queueLength(): number`
