**Part A: Add testCode() to InstanceManager**

Add a public `testCode()` method to `InstanceManager` in `packages/engine/src/instance-manager/instance-manager.ts`:

```typescript
/**
 * Dry-run code execution without creating an instance record.
 * Acquires a pool worker, runs the provided source code, releases the worker.
 * Used by MGMT-12 code test endpoint.
 *
 * NOTE: Calls this.pool.executeCode() directly, intentionally bypassing the
 * retrying executor. Dry-run failures should return the error immediately to
 * the caller — retry is not appropriate for test/validation runs.
 */
async testCode(
  sourceCode: string,
  testInputs?: Record<string, string>,
  testProps?: Record<string, unknown>,
  testActionProps?: Record<string, unknown>,
  timeoutMs?: number
): Promise<{
  success: boolean
  outputs?: Record<string, string>
  return_value?: unknown
  stdout?: string
  stderr?: string
  error?: string
  error_type?: string
  execution_time_ms: number
}> {
  const effectiveTimeout = timeoutMs ?? (this.settingsRepo.getNumericValue('execution_timeout_ms') ?? 60000)
  const startTime = Date.now()
  const result = await this.pool.executeCode(
    `test-${Date.now()}`,  // synthetic instanceId
    'TEST',                 // synthetic state
    sourceCode,
    testInputs ?? {},
    {},                     // empty outputs accumulator
    testProps ?? {},
    testActionProps ?? {},
    effectiveTimeout
  )
  const execution_time_ms = Date.now() - startTime

  if (result.success) {
    return {
      success: true,
      outputs: result.outputs ?? {},
      return_value: result.return_value,
      stdout: result.stdout ?? '',
      stderr: result.stderr ?? '',
      execution_time_ms,
    }
  }
  return {
    success: false,
    error: result.error ?? 'Unknown error',
    error_type: result.error_type,
    stdout: result.stdout ?? '',
    stderr: result.stderr ?? '',
    execution_time_ms,
  }
}
```

The pool is private, so testCode() is the only way to run code without creating an instance.

**Part B: Add code management endpoints to management.ts**

Append to the management router in `packages/server/src/routes/management.ts`, AFTER the existing dashboard/env/action/upload endpoints.

**CRITICAL route ordering:** Register literal paths BEFORE parameterized paths to avoid Express route conflicts:

```
GET  /code/:action_oid/:state/active    (literal — FIRST)
POST /code/:action_oid/:state/test      (literal — FIRST)
GET  /code/:action_oid/:state/:version_id          (parameterized — SECOND)
POST /code/:action_oid/:state/:version_id/activate (parameterized — SECOND)
DELETE /code/:action_oid/:state/:version_id        (parameterized — SECOND)
GET  /code/:action_oid/:state           (list — can be anywhere)
POST /code/:action_oid/:state           (save — can be anywhere)
```

**MGMT-07: GET /code/:action_oid/:state** (list versions)

- Validate action exists via `actionRepo.findByOid(params.action_oid)` — 404 if not
- Call `codeVersionRepo.getVersionHistory(action_oid, state)`
- Return metadata only (NOT source_code): `{ id, version_number, is_active, created_at, created_by, description, code_size: v.source_code.length }`
- Response: `{ data: { action_oid, state, versions: [...] }, meta: {} }`

**MGMT-08: GET /code/:action_oid/:state/active** (active version with source)

- Call `codeVersionRepo.getActive(action_oid, state)`
- If null, return 404 `{ error: { code: 'NOT_FOUND', message: 'No active code version for this action+state', details: {} } }`
- Return full version object including source_code
- Response: `{ data: version, meta: {} }`

**MGMT-08: GET /code/:action_oid/:state/:version_id** (specific version with source)

- Call `codeVersionRepo.findById(version_id)`
- If null or version's action_oid/state don't match params, return 404
- Return full version object including source_code
- Response: `{ data: version, meta: {} }`

**MGMT-09: POST /code/:action_oid/:state** (save new version)

- Validate action exists — 404 if not
- Validate body using `validateBody(req.body, { source_code: { required: true, type: 'string' }, description: { required: false, type: 'string' }, created_by: { required: false, type: 'string' } })`
- Call `codeVersionRepo.saveAndActivate({ action_oid, state, source_code, description, created_by })`
- Return 201: `{ data: { id, version_number, is_active: true, created_at }, meta: {} }`

**MGMT-10: POST /code/:action_oid/:state/:version_id/activate** (rollback)

- Call `codeVersionRepo.findById(version_id)` — 404 if not found or mismatched action_oid/state
- Call `codeVersionRepo.activate(version_id)` — this deactivates previous active and activates this one (rollback per CONTEXT.md decision: no new version row, just flip active flag)
- Return: `{ data: { id, version_number, is_active: true, activated_at: new Date().toISOString() }, meta: {} }`

**MGMT-11: DELETE /code/:action_oid/:state/:version_id**

- Find version via `codeVersionRepo.findById(version_id)` — 404 if not found
- Check `version.is_active === true` — if so, return 409 `{ error: { code: 'CONFLICT', message: 'Cannot delete the active version', details: {} } }`
- Check if any active instance has this version pinned:
  ```typescript
  const activeInstances = instanceRepo.findActive()
  const isPinned = activeInstances.some((inst) => {
    const pinned = inst.pinned_code_versions as Array<{ state: string; code_version_id: string }>
    return pinned.some((p) => p.code_version_id === version_id)
  })
  ```
  If pinned, return 409 `{ error: { code: 'CONFLICT', message: 'Cannot delete version pinned by running instance', details: {} } }`
- Need a delete-by-id method: CodeVersionRepository does not have `deleteById`. Use a raw prepared statement in the route:
  ```typescript
  db.prepare('DELETE FROM code_versions WHERE id = ?').run(version_id)
  ```
- Return: `{ data: { deleted: true, id: version_id }, meta: {} }`

**MGMT-12: POST /code/:action_oid/:state/test** (dry-run)

- Two modes per CONTEXT.md decision:
  1. **Syntax check only** (default — no body or empty body): Compile the currently active source code (or provided source_code) using Python's compile() — actually, simpler: call `manager.testCode(sourceCode)` with no inputs, which will execute the code. For syntax-only: if no `source_code` in body, get active version's code and test it. If body has `source_code`, test that.
  2. **Full execution** (body has source_code and optionally test_inputs/test_props): call `manager.testCode(sourceCode, testInputs, envProps, actionProps, timeoutMs)`
- Validate body (optional fields): `validateBody(req.body ?? {}, { source_code: { required: false, type: 'string' }, test_inputs: { required: false, type: 'object' }, timeout_ms: { required: false, type: 'number' } })`
- If no source_code in body: get active version via `codeVersionRepo.getActive(action_oid, state)` — 404 if none
- Resolve props: get action from `actionRepo.findByOid(action_oid)`, get environment from `environmentRepo.findByOid(action.environment_oid)`, then flatten properties for props and actionProps (use `flattenProperties` from `@trajectory/engine` if available, or build simple key-value maps)
- Call `manager.testCode(sourceCode, testInputs, envProps, actionProps, timeoutMs)`
- Return: `{ data: testResult, meta: {} }` where testResult is the object returned by testCode()

Import `flattenProperties` from `@trajectory/engine` (already exported) for property resolution in test endpoint.
