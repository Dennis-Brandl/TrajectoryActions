1. Create `packages/storage/src/repositories/code-version.repository.ts`:
   - Constructor receives `db: BetterSqlite3.Database`
   - Pre-compile all prepared statements in constructor
   - Private `fromRow(row)` method: converts is_active from 0|1 to boolean
   - Private `toRow(input)` method: converts is_active from boolean to 0|1
   - Use `crypto.randomUUID()` for generating code version IDs (Node 20+ built-in, import from `node:crypto`)
   - Methods (all synchronous):
     - `save(input: CodeVersionInput): CodeVersion` — INSERT new code version:
       a. Generate UUID for id via `crypto.randomUUID()`
       b. Auto-compute version_number: `SELECT MAX(version_number) FROM code_versions WHERE action_oid = ? AND state = ?` then +1 (start at 1)
       c. Set created_at to `new Date().toISOString()`
       d. Set is_active to `false` (0) by default
       e. INSERT and return the created CodeVersion
     - `activate(id: string): CodeVersion | null` — In a transaction:
       a. Find the code version by id
       b. If not found, return null
       c. Deactivate ALL versions for the same action_oid + state: `UPDATE code_versions SET is_active = 0 WHERE action_oid = ? AND state = ?`
       d. Activate THIS version: `UPDATE code_versions SET is_active = 1 WHERE id = ?`
       e. Return the updated code version
     - `deactivate(id: string): CodeVersion | null` — Set is_active = 0 for this version. Return updated or null.
     - `getActive(actionOid: string, state: string): CodeVersion | null` — SELECT WHERE action_oid = ? AND state = ? AND is_active = 1. Uses the partial index.
     - `getVersionHistory(actionOid: string, state: string): CodeVersion[]` — SELECT WHERE action_oid = ? AND state = ? ORDER BY version_number DESC
     - `findById(id: string): CodeVersion | null` — SELECT by PK
     - `findByAction(actionOid: string): CodeVersion[]` — All versions for an action across all states, ordered by state ASC, version_number DESC
     - `deleteByAction(actionOid: string): number` — DELETE WHERE action_oid = ?. Return count.
     - `getLatestVersion(actionOid: string, state: string): CodeVersion | null` — SELECT WHERE action_oid = ? AND state = ? ORDER BY version_number DESC LIMIT 1
     - `saveAndActivate(input: CodeVersionInput): CodeVersion` — Convenience method: save then activate in a single transaction. This is the common path for code editing.
     - `getAllActiveVersions(actionOid: string): CodeVersion[]` — Get active version for every state of an action. Useful for code pinning at instance creation time.
     - `count(): number` — SELECT COUNT(*)
     - `countByAction(actionOid: string): number` — SELECT COUNT(*) WHERE action_oid = ?
