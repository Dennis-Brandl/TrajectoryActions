**Step 2: Create `packages/server/src/sse-manager.ts`.**

SseManager class managing per-instance event buses with ring buffer replay and heartbeat.

Key design:

- `SseEvent` interface: `{ id: number, type: 'state_change' | 'output' | 'log' | 'heartbeat', data: Record<string, unknown> }`
- Private `InstanceBus` interface: `{ buffer: SseEvent[], nextId: number, listeners: Set<(event: SseEvent) => void>, heartbeatTimer: NodeJS.Timeout, terminalTimer?: NodeJS.Timeout }`
- `BUFFER_SIZE = 256`, `HEARTBEAT_MS = 30_000`, `TERMINAL_LINGER_MS = 7_000`
- `buses` is a `Map<string, InstanceBus>`
- `getOrCreateBus(instanceId)`: creates bus lazily with heartbeat setInterval that publishes `{ timestamp: new Date().toISOString() }` as heartbeat events
- `publish(instanceId, type, data)`: gets/creates bus, creates event with `bus.nextId++`, pushes to buffer (shift if > BUFFER_SIZE), notifies all listeners
- `publishStateChange(instanceId, state, previousState, instance)`: publishes `state_change` event with `{ instance_id: instanceId, state, previous_state: previousState, timestamp: new Date().toISOString() }`. Also extract output_parameters from the instance and if they are non-empty, publish an `output` event with `{ instance_id: instanceId, outputs: instance.output_parameters, timestamp: new Date().toISOString() }`
- `publishTerminal(instanceId, state, previousState, instance)`: calls publishStateChange first, then clears heartbeat timer, schedules bus deletion after TERMINAL_LINGER_MS via setTimeout, stores the timer handle in `bus.terminalTimer`
- `publishError(instanceId, message)`: publishes `log` event with `{ instance_id: instanceId, stream: 'stderr', message, timestamp: new Date().toISOString() }`
- `subscribe(instanceId, listener)`: gets/creates bus, adds listener to Set, returns unsubscribe function that removes listener
- `getEventsSince(instanceId, afterId)`: returns `bus.buffer.filter(e => e.id > afterId)` or empty array if no bus
- `shutdown()`: clears all heartbeat timers and terminal timers, clears buses Map
- Export `SseManager` class and `SseEvent` interface

Express 5 four-argument error handler middleware.

- Define `ENGINE_ERROR_STATUS_MAP`: `{ ACTION_NOT_FOUND: 404, INSTANCE_NOT_FOUND: 404, INVALID_STATE_TRANSITION: 409, PARAMETER_VALIDATION_FAILED: 400, EXECUTION_ERROR: 500, INVALID_COMMAND: 422 }`
- Error handler function with signature `(err, _req, res, _next)`:

  - If `err` is `ValidationError`: 400 with `{ error: { code: 'VALIDATION_ERROR', message: err.message, details: {} } }`
  - Default: 500 with `{ error: { code: 'INTERNAL_ERROR', message: 'Internal server error', details: {} } }`. Log `err` to console.error.
- Use `return void res.status(N).json(...)` pattern to avoid Express 5 return-type issues
- Export `errorHandler`

**Step 1: Add `cancelInstance()` to InstanceManager.**

In `packages/engine/src/instance-manager/instance-manager.ts`, add a new public method:

```typescript
/**
 * Force-cancel an instance: sends ABORT command then kills the worker process.
 * Used by DELETE /instances/:id for immediate termination semantics.
 */
async cancelInstance(instanceId: string): Promise<void> {
  // Send ABORT command through state machine (may throw if already terminal)
  try {
    await this.stateMachine.sendCommand(instanceId, 'ABORT')
  } catch {
    // Instance may already be in terminal state — that's fine for cancel
  }
  // Force-kill the subprocess if still running
  await this.pool.killWorker(instanceId)
}
```

Also add to `packages/engine/src/index.ts` — no new export needed since InstanceManager is already exported and cancelInstance is a public method on it.

function formatInstanceResponse(instance: Instance) {
  const history = instance.state_history as Array<{ state: string; timestamp: string }>
  const current = history[history.length - 1]
  const previous = history.length >= 2 ? history[history.length - 2] : null
  return {
    instance_id: instance.runtime_action_instance_id,
    action_oid: instance.action_oid,
    environment_oid: instance.environment_oid,
    workflow_instance_id: instance.workflow_instance_id,
    step_instance_id: instance.step_instance_id,

    visibility: instance.visibility,
    state: {
      current: instance.state,
      previous: previous?.state ?? null,
      entered_at: current?.timestamp ?? instance.created_at,
    },
    inputs: instance.input_parameters,
    outputs: instance.output_parameters,
    created_at: instance.created_at,
    started_at: instance.started_at,
    completed_at: instance.completed_at,
    error: instance.error,
  }
}
